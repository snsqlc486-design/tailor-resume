# /tailor-resume 워크플로우

사용자가 직업 공고 URL 또는 텍스트를 제공하면, 원본 이력서를 기반으로 해당 직무에 최적화된 이력서를 생성합니다.

## 사전 조건

- `이력서.txt` 파일이 프로젝트 루트에 존재해야 합니다.
- 사용자가 직업 공고 URL 또는 텍스트를 제공해야 합니다.

## 단계

### 1단계: 원본 이력서 읽기

`이력서.txt` 파일을 읽어 사용자의 현재 경력, 기술, 프로젝트, 학력 정보를 파악합니다.

### 2단계: 직업 공고 분석

`.agent/skills/job-analysis/SKILL.md` 스킬을 참조하여 직업 공고를 분석합니다.

- URL이 제공된 경우: `read_url_content` 도구로 페이지 내용을 읽습니다.
- 텍스트가 제공된 경우: 제공된 텍스트를 직접 분석합니다.

분석 결과로 다음을 추출합니다:
- 회사명, 직무명
- 필수 자격요건
- 우대 사항
- 핵심 키워드 및 기술스택
- 직무 설명에서 반복되는 테마

### 3단계: 매칭 분석

원본 이력서와 직업 공고를 비교하여:

1. **강하게 매칭되는 항목**: 이력서에서 직접적으로 매칭되는 경험/기술 → **강조**
2. **간접적으로 매칭되는 항목**: 직접적이지 않지만 전이 가능한(transferable) 경험 → **재구성하여 관련성 부각**
3. **매칭되지 않는 항목**: 직업 공고에서 요구하지만 이력서에 없는 항목 → **커버레터에서 학습 의지로 표현 제안**

매칭 분석 결과를 사용자에게 먼저 보여주고 확인을 받습니다.

### 4단계: 최적화된 이력서 생성

`agent.md`에 정의된 출력 형식에 따라 최적화된 이력서를 생성합니다.

**최적화 전략:**

- **경력 사항 재정렬**: 직업 공고와 가장 관련 높은 경험을 상단에 배치
- **성과 재구성**: 동일한 성과를 직업 공고의 맥락에 맞는 용어로 표현
  - 예: "보도자료 배포 29건/보도 353건" → 데이터 분석 직무라면 "데이터 기반 PR 성과 분석 및 353건의 미디어 커버리지 도출"
- **핵심 역량 요약 작성**: 직업 공고의 핵심 키워드를 포함한 3-4줄 역량 요약
- **기술 스택 정렬**: 직업 공고에서 요구하는 기술을 먼저 나열
- **불필요한 정보 축소**: 직무와 관련 없는 경험은 간략하게 처리

### 5단계: 결과 저장 및 리뷰

1. 최적화된 이력서를 `output/[회사명]_[직무명]_이력서.md` 파일로 저장합니다.
2. 사용자에게 다음을 제공합니다:
   - 최적화된 이력서 전문
   - 원본 대비 주요 변경 사항 요약
   - 추가 수정 제안 사항 (있는 경우)
3. 사용자 피드백을 반영하여 수정합니다.

### 6단계: 프로페셔널 HTML 변환 (선택)

사용자가 프로페셔널한 출력을 요청하면 `.agent/skills/pdf-export/SKILL.md` 스킬을 참조하여 스타일이 적용된 HTML 파일을 직접 생성합니다.

1. 이력서 `.md` 내용을 읽고, `templates/resume.css` 스타일을 인라인으로 포함한 HTML 파일을 `write_to_file`로 직접 생성
2. 결과물: `output/[회사명]_[직무명]_이력서.html`
3. PDF가 필요하면 브라우저에서 `Cmd+P` → PDF로 저장

> **패키지 설치 불필요** — 에이전트가 HTML을 직접 작성합니다.

### 7단계: 전문가 리뷰 (선택)

사용자가 리뷰를 요청하면 `.agent/skills/resume-review/SKILL.md` 스킬을 참조하여 다각도 리뷰를 수행합니다.

1. **👔 HR 담당자 리뷰**: 서류 통과 가능성, ATS 키워드 포함 여부, 레드 플래그 점검
2. **🎯 취업 전문가 리뷰**: 포지셔닝 전략, 스토리텔링, 차별화 포인트, 문구 개선 제안
3. 리뷰 피드백을 반영하여 이력서 `.md` 파일 수정

### 8단계: 디자인 리뷰 (선택)

HTML 이력서가 생성된 경우, 디자인 전문가 관점에서 추가 리뷰를 진행합니다.

1. **🎨 디자인 전문가 리뷰**: 가독성, 시각적 계층, 컬러, A4 인쇄 적합성 점검
2. 구체적인 CSS 수정 사항 제안 및 HTML 파일에 직접 적용

## 사용 예시

```
사용자: 이 직업에 지원하고 싶어. https://example.com/job-posting
에이전트: (위 단계를 순서대로 실행)
```

```
사용자: 이 공고에 맞춰 이력서 만들어줘.
(직업 공고 텍스트 붙여넣기)
에이전트: (위 단계를 순서대로 실행)
```
