# 📄 Resume Tailor Agent

직업 공고에 맞춰 이력서를 자동으로 최적화해주는 AI 에이전트입니다.

## 사용법

### `/tailor-resume` 워크플로우 실행

직업 공고 **URL** 또는 **텍스트**와 함께 요청하면 됩니다.

---

## 예제 프롬프트

### 1. URL로 직업 공고 제공

```
/tailor-resume
이 공고에 맞춰 이력서 만들어줘: https://www.saramin.co.kr/zf_user/jobs/relay/view?rec_idx=12345678
```

```
/tailor-resume
https://www.wanted.co.kr/wd/123456 여기에 지원하려고 해. 이력서 최적화해줘.
```

### 2. 텍스트로 직업 공고 제공

```
/tailor-resume
아래 공고에 맞춰 이력서 만들어줘.

[데이터 분석가 채용]
회사: OO컴퍼니
자격요건:
- Python, SQL 활용 가능자
- 데이터 시각화 경험 (Tableau, Power BI 등)
- 커뮤니케이션 능력 우수자
우대사항:
- 머신러닝 모델링 경험
- Streamlit 등 데이터 앱 개발 경험
```

### 3. 특정 부분 강조 요청

```
/tailor-resume
https://example.com/job/data-analyst
데이터 분석 프로젝트 경험을 특히 강조해줘.
```

### 4. 수정 요청

```
이력서 잘 만들어줬는데, 경력 사항에서 광고기획 경험도 좀 더 넣어줘.
커뮤니케이션 역량 부분을 더 강조할 수 있을까?
```

---

## 에이전트 동작 흐름

```
1. 이력서 읽기        →  이력서.txt에서 원본 경력/기술/학력 파악
2. 직업 공고 분석     →  필수요건, 우대사항, 핵심 키워드 추출
3. 매칭 분석          →  이력서 ↔ 공고 매칭률 분석 결과 제시
4. 이력서 생성        →  최적화된 이력서를 Markdown으로 생성
5. 저장 및 리뷰       →  output/[회사명]_[직무명]_이력서.md로 저장
6. PDF 변환 (선택)    →  프로페셔널한 PDF로 변환
```

---

## PDF / 프로페셔널 출력

최적화된 이력서를 **프로페셔널하게 디자인된 HTML 파일**로도 변환할 수 있습니다.
패키지 설치 없이, 에이전트가 직접 스타일이 적용된 HTML을 생성합니다.

### 에이전트에게 요청

```
이력서 프로페셔널하게 HTML로도 만들어줘
```

### PDF로 변환

생성된 `.html` 파일을 브라우저에서 열고 → `Cmd+P` → **PDF로 저장**

## 파일 구조

```
resume-tailor/
├── 이력서.txt                          # 원본 이력서 (여기를 수정하면 반영됨)
├── README.md                           # 이 파일
├── output/                             # 최적화된 이력서 저장 폴더 (md, html)
└── .agent/
    ├── agent.md                        # 에이전트 역할 및 원칙 정의
    ├── workflows/
    │   └── tailor-resume.md            # /tailor-resume 워크플로우
    └── skills/
        ├── job-analysis/
        │   └── SKILL.md                # 직업 공고 분석 스킬
        └── pdf-export/
            ├── SKILL.md                # 프로페셔널 HTML 변환 스킬
            └── templates/
                └── resume.css          # 이력서 스타일 템플릿
```

## 참고사항

- 에이전트는 이력서에 **없는 경험을 날조하지 않습니다**
- 기존 경험을 직업 공고 맥락에 맞게 **재구성하고 강조**합니다
- 원본 이력서를 업데이트하려면 `이력서.txt`를 수정하세요
